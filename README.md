## 🏎️ 關於 MONZA ATELIER
**MONZA ATELIER** 是一個結合「個人品牌深度自白」與「線上頂級超跑電商展廳」的雙軌旗艦平台。由義大利米蘭理工大學車輛工程碩士、前 Ferrari Challenge Trofeo Pirelli 領獎台車手 **Monza** 親手創立。

本平台專為全球層峰藏家獵尋極限賽道特規、經典自然進氣與絕版限量躍馬（Ferrari），提供全透明車況遙測、Ferrari Classiche 匹配號碼認證，以及全亞洲獨創的「封閉賽道副駕動態交車禮遇（Trackside Handover）」。

## 🌟 核心特色模組

### 1. 創辦人 Monza 個人全檔案 (Founder's Dossier)
- **米蘭理工大學（Politecnico di Milano）車輛工程碩士**（專攻極限空氣動力學與底盤懸吊控制）
- **英國克蘭菲爾德大學賽車工程學院**（GT3 遙測與輪胎抓地極限建模）
- **Ferrari Challenge 輝煌戰績**：4 次分站冠軍、7 次桿位、多次登上斯帕（Spa）與蒙札賽道領獎台
- **官方最高認證**：FIA 國際 C 級賽車執照、Ferrari Corso Pilota 最高階教練資格、Ferrari Classiche 古董車動態認證評估
- **完整創辦人自白（Founder's Manifesto）**

### 2. 在庫躍馬典藏與私洽配額 (Curated Stable)
- **Ferrari Daytona SP3** (Icona 限量系列 ｜ 840 cv V12)
- **Ferrari SF90 XX Stradale** (首款街道合法 XX 猛獸 ｜ 1,030 cv)
- **Ferrari 488 Pista Piloti Ferrari** (Tailor-Made 紳士車手專屬 ｜ 720 cv V8)
- **Ferrari 296 GTB Assetto Fiorano** (短軸距操駕之王 ｜ 830 cv V6 Hybrid)
- **Ferrari 458 Speciale** (最後的自然進氣純粹神話 ｜ 9,000 轉 V8)
- **Ferrari Monza SP2** (Barchetta 開放式雙座無風擋傳奇 ｜ 810 cv V12)

### 3. 四大頂級旗艦服務 (Atelier Protocols)
- **Trackside Handover 賽道交車禮遇**：封閉賽道副駕動態教學與 MoTeC 遙測
- **Global Off-Market Sourcing 全球私密獵車**：深入歐洲與日本私人車窖直購
- **Dynamics & Aerodynamics Tuning 賽道工程微調**：米蘭理工工程師團隊客製阻尼與下壓力
- **Ferrari Classiche & Escrow 原廠認證與資產託管**：匹配號碼溯源與恆溫恆濕車窖代管

### 4. 互動式私密鑑賞與訂金委託模組 (VIP Concierge Modal)
- 線上即時查看賽道遙測極限（最大側向 G 值、時速 200 km/h 下壓力、推重比、Fiorano 基準單圈）
- 線上一對一預約鑑賞與資產置換諮詢

## 🛠️ 技術棧 (Tech Stack)
- **框架**：React 18 + TypeScript + Vite
- **樣式**：Tailwind CSS (自訂 Carbon、Rosso Corsa、Giallo Modena 色系)
- **圖標庫**：Lucide React
- **字型**：Cinzel (奢華古羅馬字體) + Inter (賽車儀表級無襯線字體)
- **部署**：Vercel

## 🚀 本地開發與建置 (Local Development)

```bash
# 安裝相依套件
npm install

# 啟動本地開發伺服器
npm run dev

# 建置正式生產環境檔案
npm run build

# 預覽生產環境版本
npm run preview
```
